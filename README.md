# Caderneta de Gastos

Aplicativo simples de controle de gastos pessoais feito com React Native + Expo.

## Funcionalidades

- Cadastro de gasto com descrição e valor
- Validação com mensagem de erro visível na tela
- Lista de gastos usando FlatList
- Total acumulado atualizado automaticamente
- Exclusão de gastos
- Navegação entre duas telas
- Dados salvos apenas em memória com useState

## Como executar

```bash
npm install ou npm install --legacy-peer-deps (se houver problemas de dependências)
npx expo start
```

Depois, escaneie o QR Code com o Expo Go.
